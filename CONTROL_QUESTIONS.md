# Контрольные вопросы по Git

1. Что такое Git?
Git — система контроля версий.

2. Что такое GitHub?
GitHub — платформа для хранения проектов.

3. Что такое репозиторий?
Место хранения файлов и истории изменений.

4. Что такое commit?
Сохранение изменений в истории Git.

5. Что такое branch?
Отдельная ветка разработки.

6. Что такое merge?
Объединение веток.

7. Что такое Merge Conflict?
Конфликт изменений при объединении веток.

8. Почему возникает конфликт?
Когда Git не может автоматически объединить изменения.

9. Как разрешить конфликт?
Вручную выбрать нужные изменения и сохранить файл.

10. Что такое push?
Отправка изменений на GitHub.
